## Design Findings

- **Interface isolation**: `ModelGateway` is a pure TypeScript interface. No provider SDK types leak through. The adapter pattern is identical to the embedding provider pattern (`fake-provider.ts` in knowledge package), maintaining consistency.
- **Fake adapter for testing**: `createFakeModelGateway()` returns deterministic responses. 26 unit tests cover the full contract without external network calls.
- **Config symmetry**: The `model.*` config block mirrors `embedding.*` exactly — same field structure, same defaults/redaction pattern, same loader code path. Zero cognitive overhead for developers.
- **Error taxonomy**: 9 stable `ErrorCategory` values (`PROVIDER_UNAVAILABLE`, `RATE_LIMITED`, `CONTENT_FILTERED`, `CONTEXT_LENGTH_EXCEEDED`, `AUTHENTICATION_ERROR`, `INVALID_REQUEST`, `POLICY_DENIED`, `TIMEOUT`, `UNKNOWN`). OpenAI errors mapped through `instanceof` checks and HTTP status codes. Callers can match on category without provider knowledge.
- **Streaming contract**: `GenerationEvent` union type (`text_delta`, `tool_call_*`, `error`, `done`) normalized across providers. Future providers implement the same event shape.
- **Sensitivity policy**: Minimal `SensitivityPolicy` interface with permissive default (allows all except `PROHIBITED`). Extensible by P4 (Governed Memory) and P5 (Tool Gateway) without interface changes.
