## Design Findings

- **Cursor pagination**: Uses timestamp-based cursors on `created_at DESC`, consistent with workspace/project patterns.
- **Status filtering**: JOIN on `document_versions` for status queries — efficient for the expected data sizes.
- **Ingestion job idempotency**: Dual-layer: idempotency plugin (HTTP-level) + DB UNIQUE constraint. Fallback to existing job on collision.
- **Trace role gating**: Direct `workspace_members` query per request — simple but correct. Could be cached in a session claim for performance.
- **Type boundary**: Clean separation between knowledge package types (camelCase, readonly) and API contract types (snake_case, mutable). Transformation at route boundary is well-localized.
