2. **Cancellation with citations**: If a run is cancelled mid-stream, partial citations from the streaming parser are not persisted (by design — only completed runs produce persisted citations). Acceptable for P3; verify in P3-T07.
3. **P3-T07 dependency**: Citation verifier must validate `verification_status`, boundary checks, and current-version rules. All citations are inserted with `verification_status = 'PENDING'`.
4. **DEFAULT_PROMPT_VERSION stale**: See D01 above.
