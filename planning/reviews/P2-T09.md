## Design Findings

- **Inline HTML pattern**: Consistent with existing web shell (`apps/api/src/routes/web.ts`). Pages are generated by functions in `apps/web/src/pages/` and served from Fastify. No separate frontend build or SPA framework needed.
- **Shared design system**: `shared.ts` provides CSS, JS utilities, and shell wrapper used by all four pages. Avoids duplication.
- **Tab navigation**: Clear tab bar (Documents | Upload | Search) with active state indicator. Consistently applied across all workspace-scoped pages.
- **Accessibility-first design**: ARIA roles, live region, keyboard shortcuts, focus management, semantic HTML. Tests verify accessible markup patterns.
- **Client-side API calls**: All data fetching happens via `fetch()` in the browser. HTML pages contain no personal data. Dynamic content is escaped to prevent XSS.
- **No new endpoints**: UI calls existing P1-T07 (uploads) and P2-T08 (documents, retrieval) endpoints. Zero API surface increase.
