## Design Findings

- **Reciprocal-Rank Fusion (RRF)**: k=60 for deterministic fusion. No model dependency. RRF scores normalized to [0,1] relative to theoretical maximum.
- **Deduplication by Content Hash**: SHA-256 content hash deduplication keeps highest-scoring instance. Prevents near-duplicate chunk dominance.
- **Authorization Model**: Filters applied directly in SQL queries. Defense in depth — workspace scoping mandatory in every query.
- **Lifecycle Filtering**: READY status, current version (conditional), soft-delete checks. `includeHistorical` flag relaxes `is_current` only.
- **Trace Persistence**: Per-workspace configs persisted idempotently via `ON CONFLICT ... DO UPDATE`. Every retrieval creates trace and result rows.
- **Embedding Provider Integration**: Dependency-inversion pattern — `RetrievalService` accepts `EmbeddingProvider` + config via constructor. Provider SDK types never cross the boundary.
