## Design Decisions and Assumptions

### `encodeCursor` bug discovered and fixed

The `encodeCursor` function used `{ v: value }` (short key `v`) but the `Cursor` interface and `decodeCursor` expected `{ value: string }`. This caused `decodeCursor(encodeCursor(x))` to always return `undefined` — round-trip was completely broken. This has been latent since `encodeCursor` was introduced because no caller exercised the round-trip.

Fix: changed `{ v: value }` to `{ value }` in `encodeCursor` to match the `Cursor` interface. No persisted cursors exist, so no data migration is needed.

### Test structure

Tests follow the same `vitest` + `describe`/`it` pattern used by `@pia/config`, `@pia/auth`, `@pia/observability`, etc. Config matches `packages/config/vitest.config.ts` (globals, node environment).
