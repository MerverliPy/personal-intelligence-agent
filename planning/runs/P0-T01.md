## Design Decisions and Assumptions

1. **Volta for version management**: Installed Volta 2.0.2 to pin Node.js 22.22.3 LTS and pnpm 9.15.9, matching user-selected versions.
2. **TypeScript 5.7.3**: Installed via pnpm; the `~5.7.2` range resolved to 5.7.3.
3. **ESLint 8 (not 9)**: Chose ESLint 8.57.1 with `.eslintrc.json` for compatibility with TypeScript ESLint plugin 7.x. ESLint 9 flat config would require `typescript-eslint` v8+ which has breaking changes.
4. **Turbo 2.9.17**: Using Turborepo for task orchestration with explicit pipeline dependencies.
5. **Vitest 2.1.9**: Included as test runner; no tests exist yet (`test:unit` echoes and exits 0).
6. **App build stubs**: Web/API/Worker use `echo` stubs for build since they don't yet have frameworks installed. Turbo warns about missing outputs for these (non-blocking).
7. **Provider SDKs absent**: No framework dependencies (Next.js, Fastify, OpenAI SDK) are installed in any package. These will be added by their respective tasks.
8. **Script naming convention**: `ci:format-check` prefix established for CI-owned scripts; `format:check`/`format:fix` for developer-facing commands.
