# Regression Checklist

- [ ] Agent is available directly and as a delegated specialist.
- [ ] Five documentation commands select the correct mode.
- [ ] Three documentation skills load successfully.
- [ ] Runtime/tests/interfaces outrank prose; backlog-only work remains Planned.
- [ ] State claims use `planning/status.yaml` plus required review/run evidence.
- [ ] Planning, implementation, contracts, schemas, migrations, workflows, agents, and instructions remain read-only.
- [ ] Secret files/values are not exposed.
- [ ] Delete/move/restructure/policy/compatibility/version/commit actions request approval.
- [ ] Repository scripts are inspected and approved before execution.
- [ ] Local links, anchors, paths, commands, examples, counts, and feature claims are checked.
- [ ] Unavailable checks are Not run; failed checks are not summarized as success.
- [ ] Unrelated working-tree changes are preserved.
- [ ] Final report includes outcome, changed files, evidence, validation, blockers, gates, and suggested commit message.
